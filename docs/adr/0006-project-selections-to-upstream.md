# Project selections to the upstream generator

Upstream links use a dedicated compatibility projection rather than forwarding
the toolkit's canonical v2 hash. The projection preserves every representable
asset and color choice, chooses the visibly dominant value when upstream's
global sub-selection model cannot represent distinct asset-owned channels, and
discloses that the upstream rendering may differ. This keeps upstream links
usable without weakening asset-owned color channels from ADR-0001.
