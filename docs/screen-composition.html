整體版面

1左側素材選擇區

提供角色身形與各素材類別的選擇控制。使用者在這裡切換 body type、髮型、服裝、裝備等 layer，操作結果會立即送入組合狀態。

2中央預覽區

顯示合成後的角色 canvas，並提供動畫、方向與播放控制。背景使用棋盤格，方便檢查透明像素與 sprite 邊界。

3右側狀態與授權區

顯示目前選取 token，可複製或貼上 token 還原角色狀態。同一區也列出 attribution 與 effective license，確保素材授權資訊不會被忽略。

4頂部工具列

承載產品名稱、輔助描述、語言切換與主題切換。它是全域操作區，不直接改變角色素材，但會影響介面文字與色彩模式。

操作流程

1. 選擇角色素材

使用者先在左側面板選擇 body type，再逐項指定各素材類別。空值代表該類別不套用素材，適合用來移除服裝、武器或裝飾。

2. 產生合成結果

選取狀態會交給 composition pipeline，輸出合成 spritesheet、動畫資料與 credits manifest。中央 canvas 根據目前動畫與方向播放指定影格。

3. 調整預覽狀態

中央工具列可切換動畫名稱、方向與播放狀態。狀態文字會顯示 loading、ready 或 error，讓使用者知道目前合成與載入進度。

4. 分享或還原角色

右側 token 區把目前選擇編碼成可複製文字；貼上有效 token 後可還原同一套選擇。若 token 無效或有未解析項目，介面會顯示錯誤訊息。

狀態與錯誤顯示

載入中

中央工具列顯示 loading 與百分比，預覽區保留畫布位置，避免使用者在素材載入期間失去畫面脈絡。

合成失敗

若角色合成或素材載入失敗，中央預覽區會改顯示錯誤訊息，文字使用 danger 色彩，方便和一般狀態區分。

Token 操作

複製成功、套用成功、複製失敗、格式錯誤或 unresolved selection 都會在右側 token 區以短訊息回饋。

授權資訊

只要合成結果帶有 credits，就顯示 effective license 與逐項素材來源。這是 LPC Toolkit 的必要資訊，而不是附加內容。

響應式組成

桌面版以三欄格線呈現，讓「選素材、看預覽、查授權」可以同時可見。窄螢幕下會改成單欄堆疊：先保留全域工具列，再依序顯示素材選擇、預覽與 token/授權資訊，確保內容不被壓縮到難以操作。
