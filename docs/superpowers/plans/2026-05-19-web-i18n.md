# Web i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add English and Traditional Chinese translations to the web UI, with English as the default locale and a header language toggle.

**Architecture:** Use a typed local i18n module with `en` and `zh-TW` dictionaries. `App` owns locale state and passes a translator plus toggle handler to `SliceHarness`, which renders translated fixed UI labels while leaving catalog-derived data unchanged.

**Tech Stack:** React 18, TypeScript, Vite, Vitest, pnpm workspace.

---

## File Structure

- Create `packages/web/src/i18n.ts`: owns locale types, default locale, translation dictionaries, and translator creation.
- Create `packages/web/test/i18n.test.ts`: verifies default locale, key parity, and representative translated labels.
- Modify `packages/web/src/App.tsx`: owns locale state and passes translation props to `SliceHarness`.
- Modify `packages/web/src/components/slice-harness.tsx`: renders translated fixed labels and adds the language toggle button.

```ts
import { describe, expect, it } from 'vitest';
import {
  DEFAULT_LOCALE,
  TRANSLATIONS,
  createTranslator,
  type TranslationKey,
} from '../src/i18n';

describe('i18n', () => {
  it('defaults to English', () => {
    expect(DEFAULT_LOCALE).toBe('en');
  });

  it('keeps English and Chinese translation keys in sync', () => {
    const englishKeys = Object.keys(TRANSLATIONS.en).sort();
    const chineseKeys = Object.keys(TRANSLATIONS['zh-TW']).sort();

    expect(chineseKeys).toEqual(englishKeys);
    expect(englishKeys).toContain('app.subtitle' satisfies TranslationKey);
  });

  it('translates representative labels', () => {
    const en = createTranslator('en');
    const zh = createTranslator('zh-TW');

    expect(en('controls.play')).toBe('Play');
    expect(en('direction.left')).toBe('Left');
    expect(zh('controls.play')).toBe('播放');
    expect(zh('direction.left')).toBe('左');
  });
});
```

```ts
export type Locale = keyof typeof TRANSLATIONS;
export type TranslationKey = keyof (typeof TRANSLATIONS)['en'];
export type Translator = (key: TranslationKey) => string;

export const DEFAULT_LOCALE: Locale = 'en';

export function createTranslator(locale: Locale): Translator {
  return (key) => TRANSLATIONS[locale][key];
}
```

- [ ] **Step 3: Modify `App` to own locale state**

```tsx
import { useMemo, useReducer, useState } from 'react';
import {
  DEFAULT_LOCALE,
  createTranslator,
  type Locale,
} from './i18n';

const [locale, setLocale] = useState<Locale>(DEFAULT_LOCALE);
const t = useMemo(() => createTranslator(locale), [locale]);

locale={locale}
t={t}
onToggleLocale={() =>
  setLocale((current) => (current === 'en' ? 'zh-TW' : 'en'))
}
```
