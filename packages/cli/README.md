# @lpc-toolkit/cli

Node 22+ CLI for cataloging, validating, and rendering attributed LPC character sprites.

Install it globally:

```sh
npm install -g @lpc-toolkit/cli
```

The package installs the `lpc-toolkit` binary. The first asset-dependent command downloads about 205 MB of compressed assets; subsequent commands reuse the cache and can run offline.

Rendered output always includes attribution. This package is licensed under GPL-3.0-or-later.
